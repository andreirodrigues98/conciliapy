# ConciliaPy

Sistema inteligente de conciliação financeira por planilhas.

## Status

Projeto em desenvolvimento.

Importar, organizar, validar, comparar e conciliar informações financeiras presentes em planilhas.

- Streamlit
- SQLite
- SQLAlchemy
